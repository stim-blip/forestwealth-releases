This repository contains **release binaries only**. The application source is private.

ForestWealth lets a household or group keep one shared wallet: record income and expenses together, browse the
history, see statistics, and get a notification for every change made by anyone in the wallet.

| Area | What it does |
| :--- | :--- |
| **Shared wallet** | Join a wallet with a role and PIN; every member sees the same balance and history. |
| **Transactions & statistics** | Income and expenses by category, full history, and charts. |
| **Live notifications** | A system notification for every add, edit or delete — even when the app is closed. |
| **Security** | Supabase Auth with row-level security; too many wrong PINs locks the wallet for 15 minutes. |
| **Self-updating** | The app checks `version.json` in this repository and offers new releases. |

## Install

1. Open the [latest release](https://github.com/stim-blip/forestwealth-releases/releases/latest) and download `ForestWealth-vX.Y.Z.apk` on your phone.
2. Allow installation from your browser or file manager when Android asks.
3. Open ForestWealth.

> Upgrading from a build older than **v1.0.0**? Uninstall the old app first.
